## 1. 目的と範囲
### 1.1 目的
Devsisters「クッキーラン」シリーズ（キングダム／オーブンブレイク）の代表キャラを、動きのある見た目で眺められる個人用の図鑑を作る。あわせて、この図鑑を紹介する宣伝ページ（`/promo`）を同じアプリ内に作る。

### 1.2 利用条件
- 利用者は本人のみ。非公開・非商用。
- PC ブラウザ（1280px 以上が主対象）。ローカルで実行する（`npm run dev` / `npm run preview`）。
- ログイン、DB、サーバー、ホスティングは使わない。

### 1.3 範囲外
自分のキャラを作って会話する機能、公開・デプロイ、スマホ最適化、全キャラの自動取得、YouTube のダウンロード、音声、`hero.mp4` の制作そのもの。

## 2. システム構成
```
            ┌─ 開発時に1回だけ実行 ───────────────────────────┐
            │ scripts/fetch-assets.mjs                        │
            │  cookierun.wiki MediaWiki API ─▶ 項目・画像・GIF │
            │  sharp: GIF ─▶ アニメーション WebP + 静止画     │
            └──────┬──────────────────────────┬───────────────┘
                   ▼                          ▼
        src/data/characters.json     public/assets/**（.gitignore）
        src/data/timeline.json       public/promo/**（.gitignore）
                   │                          │
                   ▼                          ▼
   ┌───────────── ブラウザ（React SPA / Vite でビルド）──────────────┐
   │ ルーター(/, /promo, 404)                                         │
   │  ├ 図鑑 / : 一覧・検索 | ステージ(3Dカード/動作) | 説明パネル     │
   │  └ 宣伝 /promo : 動画枠 | スクロール連動の年表 | CTA             │
   │ 共通: Motion（動き）/ 自前 Canvas（粒子）/ Tailwind（見た目）     │
   └─────────────────────────────────────────────────────────────────┘
```
- 実行時にサーバーは使わない。データは JSON をビルドに取り込み、画像は静的ファイルとして配信する。
- 外部通信は、Google Fonts の読み込みのみ（実行時）。MediaWiki API へのアクセスは素材取得スクリプトの実行時だけ。

## 4. 画面設計（概要）
詳細は [UI.md](UI.md)。

| ID | パス | 画面 | 概要 |
|---|---|---|---|
| S1 | `/` | 図鑑 | 左: 一覧（検索・フィルタ）／中央: ステージ（3Dカード・動作表示）／右: 説明パネル |

## 5. 機能設計（概要）
PRD の機能 ID に対応する。受け入れ基準は PRD 4章（AC-01〜AC-67）。

| ID | 機能 | 要点 |
|---|---|---|
| M-01 | 静的キャラデータ | `characters.json`（10体）。型と検証テストを持つ |
| M-02 | 素材の取得・変換 | 開発時に1回だけ実行。取れなかった素材は一覧で報告する |
| M-03 | タイトルタブ | キングダム／オーブンブレイクの切替 |
| M-04, M-05 | 一覧・選択・説明パネル | サムネ一覧、概要／スキル／登場のタブ、出典とライセンス表示 |
| M-06 | 3D 回転カード | ドラッグで回転、ダブルクリックで正面、表は立ち絵・裏はステータス |
| M-07 | ステージ表示 | 動作 WebP を切替。素材がなければ代替演出 |
| M-08 | 検索・フィルタ | 正規化した部分一致、等級・役割の絞り込み、0件表示 |
| M-09 | キーボード操作 | ←/→ で切替、Enter でスキル |
| M-10 | 動きを減らす設定 | OS の `prefers-reduced-motion` に従う |
| M-11 | エラー表示 | 素材欠け・動画なしでも画面を壊さない |
| M-12 | 宣伝ページ | `hero.mp4` の枠と代替、年表、走る演出、CTA |
| S-01〜05 | 慣性、傾き・光沢、待機の揺れ、スキル演出、URL 同期 | v1 で実装する（リード決定） |

## 6. データ設計（概要）
- `Character`（[src/types/character.ts](../src/types/character.ts)）: id、title、names（ja/en/ko）、rarity、role、position、summary、skill、images、motions、sourceUrl、license、imageCredit、fetchedAt など。
- 1タイトル1エントリ。両タイトルにいるキャラは `baseId` で結ぶ。
- `MotionAsset`: `{ id, label, src, still, loop, isSkill? }`。`still` は reduced-motion 用の静止画。
- `TimelineItem`: `{ year, title, summary, sourceUrl }`（[src/types/timeline.ts](../src/types/timeline.ts)）。
- 素材のパス: `/assets/{crk|crob}/{slug}/{motionId}.webp`、立ち絵は `illustration.webp`、サムネは `thumb.webp`。

## 7. 外部インターフェース
| 相手 | 用途 | 方法 | 注意 |
|---|---|---|---|
| cookierun.wiki | キャラ項目、画像、GIF の取得 | MediaWiki API（`/mw/api.php`）。開発時のみ | 逐次実行、1秒間隔、連絡先付き User-Agent（`.env` の `WIKI_USER_AGENT`）。結果をキャッシュ |
| Google Fonts | フォント | `<link>`（実行時） | オフラインならシステムフォントに代替 |
| claude.ai の Claude Motion | 宣伝ページの動画 | 本人が MP4 を書き出して `public/promo/hero.mp4` に置く | 報道ベースの機能。公式の告知は未確認。ファイルがなければ代替表示 |

## 8. 非機能要件
| 項目 | 内容 |
|---|---|
| 性能 | `npm run preview` で最初の立ち絵が3秒以内に出る（AC-64）。一覧にはサムネ（300px）を使い、原寸は選択時に読む |
| 互換性 | 最新の Chromium 系ブラウザ（Playwright の対象）を主対象とする |
| アクセシビリティ | キーボード操作、フォーカス表示、コントラスト 4.5:1 以上、ドラッグの代替操作、点滅の抑制（[UI.md](UI.md) 6章） |
| 動きの配慮 | `prefers-reduced-motion` で慣性・揺れ・粒子・視差を止める（AC-47〜50） |
| 保守性 | キャラの追加は JSON に1件足して素材スクリプトを実行するだけ（US-13） |
| セキュリティ | 認証情報を持たない。`.env` はコミットしない。外部リンクは `rel="noopener noreferrer"` |
| 運用 | ローカル実行のみ。デプロイしない |

## 9. 権利・制約
- 画像・動作素材の著作権は Devsisters にある。ローカルの非公開利用に限り、`public/assets/`・`public/promo/` は `.gitignore` で配布しない。
- 画面に「© Devsisters」と出典（cookierun.wiki、CC BY-SA 4.0）を表示する。
- スキル説明は原文を転載せず、手作業で要約する。
- ゲームのデータから抜き出した素材（Datamined と記載されたもの）が含まれる。個人利用に限り、リポジトリを公開する場合も素材は含めない。

## 10. 開発・実行環境
| 目的 | コマンド |
|---|---|
| 開発サーバー | `npm run dev` |
| ビルド・確認 | `npm run build` / `npm run preview`（4173） |
| 静的解析 | `npm run check` |
| 単体テスト | `npm test` |
| E2E | `npm run e2e` |
| 素材取得・変換 | `npm run assets` |

社内ネットワークで `npm install` が証明書エラーになる場合は、`NODE_OPTIONS=--use-system-ca` を付ける。npm 10.9.8 は `vitest` の peer 依存の解決で失敗するため、`--legacy-peer-deps` も付ける。
