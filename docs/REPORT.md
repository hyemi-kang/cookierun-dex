## レビューの指摘と対応
| 重大度 | 内容 | 対応 |
|---|---|---|
| 中 | 裏返しが効かない角度がある（100°や-10°で止まったとき） | 最寄りの面を基準に反対側へ回すよう修正 |
| 低 | 戻る/進むでゲームだけ変わり、検索・フィルタが残る | game が変わったらフィルタを外す |
| 低 | 動きを減らす設定のときの裏返しが、リセットやドラッグと競合する | 中断できるようにした |
| 低 | スキル演出中にキャラを切り替えると、名前・色が途中で変わる | 発動時点の値を最後まで使う |
| 低 | 取得スクリプトの堅牢性（エラー応答のキャッシュ、タイムアウトなし、URL 解析、100件超、ホスト検証、id 検証） | すべて反映 |
| 低 | 状態更新の関数の作り直し、判定の2系統、見えないボタンへのフォーカス | 修正 |

## つまずいた点と対応
| 事象 | 原因 | 対応 |
|---|---|---|
| `npm install` が10分以上進まない | npm 10.9.8 が `vitest` の peer 依存の解決で落ちる | `--legacy-peer-deps` を付ける |
| パッケージ本体の取得が `UNABLE_TO_VERIFY_LEAF_SIGNATURE` | 社内ネットワークの証明書 | `NODE_OPTIONS=--use-system-ca`（Windows の証明書を信頼。検証は切らない） |
| curl で `registry.npmjs.org` に繋がらない | Windows の証明書失効確認（`CRYPT_E_REVOCATION_OFFLINE`） | npm 自体は通る。npm で確認した |
| Biome の移行で lint のルールが全部切れた | `biome migrate` が `preset: "none"` にした | `recommended` に戻し、Tailwind の記法を読めるようにした |
| 調査Bの報告に誤り | 並列取得で古い値が混じった | user-event と jest-dom は使えると訂正（必要になったら追加） |
| 止まった `npm install` を止めるため PID だけで `node.exe` を強制終了 | npm のものか未確認だった | 反省点。他の Node プロセスが落ちていたら再起動する。以降はポートで特定して止めた |
| E2E が他担当のビルドとぶつかった（ポート4173） | `webServer` を共有していた | 最終確認はリードが1回で実行する運用にした |
| データ担当が600秒進まず停止 | 長い待機コマンド | 状態を確認して、残りを引き継いだ |
| 素材パス `/assets/` と Vite の出力先 `dist/assets/` が同名 | Vite の既定値 | `build.assetsDir` を `_app` に変更 |
