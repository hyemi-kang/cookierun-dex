## 1. 概要

### 1.1 目的
Devsisters「クッキーラン」シリーズのうち **キングダム** と **オーブンブレイク** の代表キャラを、動きのある見た目で眺められる個人用の図鑑 Web アプリを作る。

- 選んだキャラを中央に大きく出す。ドラッグで Y 軸回転するカード（表は立ち絵、裏はステータス）にする。
- 右側に説明パネルを出す。
- 「ステージ表示」では動作アニメーションを切り替えられる。スキル発動時は演出を重ねる。
- あわせて、図鑑を紹介する宣伝ページ `/promo` を同じアプリの中に作る。

### 1.2 想定ユーザー
- **本人のみ**（開発者兼ファン）。公開も商用利用もしない。
- PC ブラウザで使う（主対象は幅 1280px 以上）。狭い画面では、崩れずに操作できれば十分とする。
- ローカルで動かす（`npm run dev` / `npm run preview`）。ログイン・DB・ホスティングは使わない。

### 1.3 成功の目安
- 代表キャラ約 10 体（両タイトル合計）の閲覧・回転・動作再生・検索がローカルで最後まで動く。
- `/promo` をスクロールすると、年表と走るキャラの演出が最後まで見られ、CTA から図鑑へ移れる。
- キャラ追加は「JSON に 1 件足す + スクリプトで素材を変換する」だけで済み、コードの変更はいらない。

### 1.4 画面構成（ルート）
| パス | 画面 |
|---|---|
| `/` | 図鑑（タブ・検索/フィルタ・キャラ一覧・中央の回転カード/ステージ・右の説明パネル） |
| `/promo` | 宣伝ページ（動画枠 → スクロール連動の年表 → CTA） |

## 2. MVP 機能一覧

方針：Must は「これがないと図鑑として使う意味がない」ものに限る。Should は v1 で実装予定だが、遅れた場合は v1.1 に回せるもの。Could は余裕があれば作るもの。

### Must
| ID | 機能 | 概要 |
|---|---|---|
| M-01 | 静的キャラデータと検証 | `characters.json`（両タイトルで約 10 体）。型と検証テストを付け、後から追加しやすい構造にする。出典（`sourceUrl`）とライセンスを持たせる。 |
| M-02 | 素材の取得・変換スクリプト | 開発時に 1 回だけ実行する。cookierun.wiki の MediaWiki API からインフォボックス項目と画像を取得し、sharp で GIF をアニメーション WebP に変換する。出力先は `.gitignore` の対象にする。 |
| M-03 | タイトルタブ | キングダム / オーブンブレイクを切り替える。 |
| M-04 | キャラ一覧と選択 | サムネイル一覧。クリックで選ぶと、中央表示と右パネルが切り替わる。 |
| M-05 | 説明パネル | 名前（日本語/英語/韓国語）、等級、ポジション、役割、初登場、実装日、スキル要約、出典リンク、ライセンスを表示する。 |
| M-06 | 3D 回転カード | Y 軸回転のカード（表は立ち絵、裏はステータス）。ドラッグで回転し、ダブルクリックで正面に戻る。 |
| M-07 | ステージ表示と動作切替 | 動作 WebP をボタンで切り替える。素材がないキャラは、プログラムの演出（跳ねる、つぶれて伸びる）で代わりにする。 |
| M-08 | 検索・フィルタ | 名前の部分一致（NFKC 正規化・小文字化・ひらがな/カタカナの違いを吸収）と、等級・役割での絞り込み。0 件のときの表示も出す。 |
| M-09 | キーボード操作 | ←/→ で、表示中の一覧の前後のキャラに切り替える。 |
| M-10 | prefers-reduced-motion 対応 | 自動で動く演出を止めるか弱める。 |
| M-11 | エラー状態の表示 | 画像・動作素材・動画が読み込めないときに代わりの表示を出し、画面を壊さない。 |
| M-12 | 宣伝ページ `/promo`（基本） | 動画差し込み枠と代わりの表示、スクロールで進む年表、勇敢なクッキーがスクロールに連動して走る演出、図鑑への CTA。 |

### Should
| ID | 機能 | 概要 |
|---|---|---|
| S-01 | 回転の慣性 | ドラッグを離した後も速度に応じて回り続け、だんだん止まる。 |
| S-02 | マウス追従の傾きと光沢 | カーソル位置に合わせてカードが少し傾き、光沢が動く。 |

| S-05 | URL とキャラの同期 | `/?c=<id>` で特定のキャラを直接開ける（再読み込みしても選択が残る）。 |

## 4. 受け入れ基準

確認方法の凡例: **[U]** Vitest + Testing Library、**[E]** Playwright（`npm run preview` で起動したビルド版に対して実行）、**[S]** スクリプトの実行結果、**[M]** 目視確認。

### 4.1 データ JSON の検証（M-01）
- **AC-01** [U] `characters.json` のすべての要素が `Character` 型のスキーマ検証に通る。必須項目は `id`, `title`, `names.ja`, `names.en`, `rarity`, `summary`, `images.illustration`, `sourceUrl`, `license`。1 件でも違反があればテストが失敗する。
- **AC-02** [U] `id` はファイル全体で重複しない。形式は `^(crk|crob)-[a-z0-9-]+$`。
- **AC-03** [U] `title` は `"kingdom"` か `"ovenbreak"` のどちらか。`rarity` と `role` は、タイトルごとに決めた列挙値のいずれか。
- **AC-04** [U] すべての `sourceUrl` が `https://cookierun.wiki/` で始まる。`license.text` は `"CC BY-SA 4.0"` である。
- **AC-05** [U] キャラ数は両タイトル合計で 8 件以上 12 件以下。各タイトルに 3 件以上ある。
- **AC-06** [U] `motions` の各要素の `id` は、そのキャラの中で重複しない。`src` は `/assets/` で始まる相対パスである。
- **AC-07** [S] 取得・変換スクリプトを実行すると、JSON に書かれた全キャラの立ち絵と動作素材が `.webp` で出力される。取得できなかったものは、キャラ ID と素材名の一覧としてコンソールに出る。スクリプトは終了コード 0 で終わる。素材がないこと自体はエラーにしない。
- **AC-08** [S] スクリプトの出力先ディレクトリが `.gitignore` に含まれている。`git status` に画像ファイルが出ない。
- **AC-09** [S] 変換後のアニメーション WebP は 1 ファイル 3MB 以下。超えた場合は、スクリプトが警告にファイル名とサイズを出す。

### 4.2 タブ切替（M-03）
- **AC-10** [E] 初期表示ではキングダムのタブが選ばれており、一覧には `title: "kingdom"` のキャラだけが出る。
- **AC-11** [E] オーブンブレイクのタブをクリックすると、500ms 以内に一覧が `title: "ovenbreak"` のキャラだけになり、そのタブに `aria-selected="true"` が付く。
- **AC-12** [E] タブを切り替えると、切り替え先の一覧の先頭キャラが選択状態になり、中央と右パネルがそのキャラの表示になる。
- **AC-13** [E] タブを切り替えても、検索欄の文字列はそのまま残り、切り替え先のタイトルに対して検索が効く。

### 4.3 一覧と選択（M-04, M-05）
- **AC-14** [E] 一覧のキャラをクリックすると、1 秒以内に中央カードの立ち絵の `alt` がそのキャラの `names.ja` になり、右パネルの見出しにも `names.ja` が出る。
- **AC-15** [E] 選択中のキャラには `aria-current="true"` が付き、見た目でも選択中とわかる（枠線などのスタイルが変わる）。
- **AC-16** [E] 右パネルに、等級・ポジション・役割・初登場・実装日・スキル名・スキル要約・出典リンク・ライセンス表記が出る。データにない項目は「不明」と表示し、空欄にしない。
- **AC-17** [E] 右パネルの出典リンクは、そのキャラの `sourceUrl` を `target="_blank" rel="noopener noreferrer"` で開く。画像の権利表記「© Devsisters」も出る。

### 4.4 回転カード（M-06, S-01〜S-03）
- **AC-18** [E] カード上で水平方向に 200px ドラッグすると、カードの Y 軸回転角が 90° 以上変わる。ドラッグ量と回転角の比率は実装定数で決め、テストはその定数を参照する。
- **AC-19** [E] 回転角が 90°〜270°（mod 360）のときは裏面（ステータス面）が見え、それ以外のときは表面（立ち絵）が見える。裏面には等級・役割・ポジションが出る。
- **AC-20** [E] カードをダブルクリックすると、800ms 以内に回転角が 0°（正面）に戻る。
- **AC-21** [U/E] (S-01) 速くドラッグして離すと、離した後も回転角が変わり続け、2 秒以内に止まる。ゆっくりドラッグして離した場合は、離した直後に止まる（慣性による変化が 5° 未満）。
- **AC-22** [M] (S-02) カード上でカーソルを動かすと、カードが最大 ±15° の範囲で傾き、光沢がカーソルの方向に動く。カーソルがカードから外れると 500ms 以内に傾きが 0 に戻る。
- **AC-23** [M] (S-03) 3 秒間操作しないと、カードが上下にゆっくり揺れ始める。操作を始めるとすぐ止まる。
- **AC-24** [E] 別のキャラを選ぶと、回転角は 0° に戻る。

### 4.5 ステージ表示・動作切替（M-07）
- **AC-25** [E] 「ステージ表示」に切り替えると、カードの代わりにステージ領域が出る。そのキャラの `motions` の数だけ動作ボタンが並ぶ。
- **AC-26** [E] 動作ボタン（例: `run`）をクリックすると、ステージの画像の `src` がその動作の WebP に変わり、ボタンに `aria-pressed="true"` が付く。
- **AC-27** [E] `motions` が空のキャラでステージ表示を開くと、立ち絵とともに「跳ねる」「つぶれて伸びる」の 2 つのボタンが出る。押すと、立ち絵に対応する CSS/Motion アニメーションが付く（例: `data-fallback-motion="bounce"` 属性が付く）。
- **AC-28** [E] ステージ表示のままキャラを切り替えると、新しいキャラの最初の動作（`idle` か `run`。どちらもなければ代替演出）に切り替わる。
- **AC-29** [E] 「カード表示」に戻すと、回転カードが正面向きで出る。

### 4.6 スキル演出（S-04）
- **AC-30** [E] ステージ表示で「スキル発動」ボタンを押すと、200ms 以内にスキル名のカットイン（`names` ではなく `skill.name` の文字列）が表示され、2.5 秒以内に消える。
- **AC-31** [E] スキル発動中は、パーティクル用の `<canvas>` が DOM にあり、演出が終わると取り除かれるか非表示になる。
- **AC-32** [E] スキル発動中に「スキル発動」を連打しても、演出は同時に 1 つしか再生されない（ボタンは演出が終わるまで無効になる）。
- **AC-33** [E] `skill1` の動作素材があるキャラでは、スキル発動中にステージの画像が `skill1` に切り替わり、演出が終わると直前の動作に戻る。素材がないキャラでは、代替演出の「つぶれて伸びる」を使う。
- **AC-34** [M] フラッシュは全画面を 1 回だけ白く光らせ、300ms 以内に消える。画面揺れは 500ms 以内に止まる。

### 4.7 検索・フィルタ（M-08）
- **AC-35** [U] 正規化関数は、次の入力をすべて同じキーに変換する: 「ホリーベリー」「ほりーべりー」「ﾎﾘｰﾍﾞﾘｰ」（半角カナ）。
- **AC-36** [U] 正規化関数は「ＤＡＲＫ」（全角）と「dark」を同じキーに変換する。
- **AC-37** [E] 検索欄に「ばにら」と入力すると、300ms 以内に一覧が「ピュアバニラクッキー」を含むキャラだけになる。
- **AC-38** [E] 英語名でも当たる。「brave」と入力すると、勇敢なクッキー（GingerBrave）が一覧に出る。
- **AC-39** [E] 等級フィルタで「Legendary」を選ぶと、一覧のすべてのキャラの等級が Legendary になる。役割フィルタと組み合わせた場合は AND 条件で絞り込む。
- **AC-40** [E] 該当が 0 件のとき、一覧の場所に「該当するクッキーが見つかりません」というメッセージと「条件をクリア」ボタンが出る。ボタンを押すと、検索欄とフィルタがすべて初期状態に戻り、そのタブの全キャラが出る。
- **AC-41** [E] 絞り込みの結果、選択中のキャラが一覧から消えた場合は、結果の先頭キャラを選ぶ。0 件のときは、中央と右パネルに「キャラを選んでください」という空の状態を出す。
- **AC-42** [E] オーブンブレイクのタブでは、データに `role` がない場合、役割フィルタは無効表示になるか非表示になる。

### 4.8 キーボード操作（M-09）
- **AC-43** [E] 検索欄以外にフォーカスがある状態で → を押すと、表示中の一覧の次のキャラが選ばれる。← なら前のキャラが選ばれる。
- **AC-44** [E] 一覧の最後で → を押すと先頭に戻り、先頭で ← を押すと最後に移る。
- **AC-45** [E] 検索欄にフォーカスがある間は、←/→ でキャラは切り替わらない（入力欄のカーソル移動になる）。
- **AC-46** [E] タブ・一覧・動作ボタン・スキル発動ボタンは、Tab キーでたどれて、フォーカスが見た目でわかる。

### 4.9 prefers-reduced-motion（M-10）
Playwright では `page.emulateMedia({ reducedMotion: 'reduce' })` を使って確認する。
- **AC-47** [E] reduce のとき、待機中の揺れ・マウス追従の傾き・回転の慣性は動かない（ドラッグを離した直後に回転角が変わらなくなる）。ドラッグによる回転とダブルクリックでのリセットは使える。
- **AC-48** [E] reduce のとき、スキル発動ではフラッシュ・画面揺れ・パーティクルを出さず、スキル名だけを表示する。
- **AC-49** [E] reduce のとき、ステージ表示の動作素材は自動で再生しない。最初は静止画（立ち絵）を出し、動作ボタンを押したときだけ再生する。
- **AC-50** [E] reduce のとき、`/promo` の走るキャラはアニメーションではなく静止画を出し、年表は普通にスクロールして読める。

### 4.10 宣伝ページ /promo（M-12）
- **AC-51** [E] `/promo` を開くと、冒頭に動画枠が出る。`public/promo/hero.mp4` があれば、`<video muted autoplay loop playsinline>` で再生される。
- **AC-52** [E] `hero.mp4` がない、または読み込めないときは、`video` の error を受けて代わりの表示（タイトルロゴの文字と静止画）に切り替わる。コンソールに未処理の例外が出ない。
- **AC-53** [E] 年表には 4 項目以上（OvenBreak / for Kakao / OvenBreak(2016) / Kingdom）が年の昇順に並ぶ。各項目に年・タイトル名・概要の 1 文が出る。
- **AC-54** [E] ページを一番下までスクロールすると、走るキャラ要素の横位置（`transform` の X）が、スクロール開始時より大きくなっている。スクロールを途中まで戻すと位置も戻る（スクロール量に連動していて、時間に連動していない）。
- **AC-55** [E] 年表の項目は、画面に入ったときにフェードイン/スライドインし、入った後は `opacity` が 1 になる。
- **AC-56** [E] ページの最後の CTA「図鑑を見る」をクリックすると `/` に移り、図鑑が表示される。
- **AC-57** [E] `/` から `/promo` へのリンクがヘッダーにある。`/promo` からも `/` に戻れる。
- **AC-58** [M] 年表の年と出来事は、実装時に cookierun.wiki で確認する。確認した出典 URL を年表データに書く。

### 4.11 エラー状態（M-11）
- **AC-59** [E] 立ち絵が読み込めない（404）とき、カードの表面に、キャラ名とプレースホルダー画像の代わりの表示が出る。回転などのほかの操作はそのまま使える。
- **AC-60** [E] 一覧のサムネイルが読み込めないとき、名前の頭文字を出したプレースホルダーに置き換わる。一覧の並びは崩れない（要素の高さが変わらない）。
- **AC-61** [E] 動作素材が読み込めないとき、ステージは代替演出（跳ねる）に切り替わり、「この動作は読み込めませんでした」という通知を 3 秒間出す。
- **AC-62** [E] 素材ディレクトリが丸ごとない状態（スクリプト未実行）でアプリを起動しても、白い画面にならない。全キャラがプレースホルダーで表示され、データと検索は使える。
- **AC-63** [E] 存在しないパス（例: `/foo`）を開くと、「ページが見つかりません」と `/` へのリンクが出る。

### 4.12 非機能
- **AC-64** [E] `npm run preview` で起動し、`/` を開いてから最初のキャラの立ち絵が表示されるまで 3 秒以内（ローカル環境）。
- **AC-65** [E] 幅 1280px では一覧・中央・右パネルが横に 3 列で並ぶ。幅 768px では、横スクロールバーが出ずに全部の機能を操作できる。
- **AC-66** [S] `biome check` と `vitest run` がエラーなしで終わる。
- **AC-67** [S] ソースコードに API キーや認証情報が書かれていない。MediaWiki API へのアクセスには、スクリプトから連絡先付きの User-Agent を設定し、その値は環境変数から読む（`.env.example` に項目を書く）。

## 5. データモデル案（Character 型）

```ts
export type GameTitle = "kingdom" | "ovenbreak";

// 列挙値は実装時に wiki の分類と合わせて確定する（仮）
export type KingdomRarity =
  | "Common" | "Rare" | "Epic" | "SuperEpic" | "Legendary"
  | "Ancient" | "Dragon" | "Special";
export type OvenBreakRarity =
  | "Common" | "Rare" | "Epic" | "Legendary" | "Special" | "Ancient";

export type KingdomRole =
  | "Charge" | "Defense" | "Magic" | "Ranged"
  | "Support" | "Healing" | "Bomber" | "Ambush";
export type KingdomPosition = "Front" | "Middle" | "Rear";

export interface LocalizedName {
  ja: string;          // 表示と検索の主キー
  en: string;          // 例: "GingerBrave"
  ko?: string;
  aliases?: string[];  // 旧名・略称など、検索で当てたい追加の名前
}

export interface MotionAsset {
  id: string;          // "idle" | "battle_idle" | "run" | "jump" | "skill1" など
  label: string;       // ボタンの表示名（日本語）
  src: string;         // "/assets/crk/gingerbrave/run.webp"
  loop: boolean;
  isSkill?: boolean;   // スキル発動演出で使う素材か
}

export type FallbackMotion = "bounce" | "squash";

export interface Skill {
  name: string;        // スキル名（日本語）
  summary: string;     // 手作業で書いた要約（原文を転載しない）
}

export interface Character {
  id: string;                     // "crk-gingerbrave" / "crob-gingerbrave"
  baseId?: string;                // タイトルをまたいで同じキャラを結ぶキー（例: "gingerbrave"）
  title: GameTitle;
  order: number;                  // 一覧での並び順
  names: LocalizedName;
  rarity: KingdomRarity | OvenBreakRarity;
  position?: KingdomPosition;     // キングダムのみ
  role?: KingdomRole;             // キングダムのみ
  firstAppearance?: string;       // インフォボックスの first_appearance
  releaseDate?: string;           // ISO 8601 (YYYY-MM-DD)。不明なら省略
  summary: string;                // キャラ説明（手作業で要約）
  skill?: Skill;
  images: {
    illustration: string;         // 立ち絵
    thumbnail?: string;           // 省略時は立ち絵を縮小して使う
  };
  motions: MotionAsset[];         // 空配列なら代替演出を使う
  fallbackMotions?: FallbackMotion[]; // 省略時は ["bounce", "squash"]
  theme?: { accent: string };     // カードの光沢・パーティクルの色 (#RRGGBB)
  sourceUrl: string;              // cookierun.wiki の該当ページ
  license: { text: "CC BY-SA 4.0"; url: string };
  imageCredit: string;            // "© Devsisters"
  fetchedAt: string;              // スクリプトで取得した日時 (ISO 8601)
}
```

補足
- **1 タイトル 1 エントリ**とする。勇敢なクッキーのように両方のタイトルにいるキャラは、`baseId` で結ぶ。等級や素材がタイトルごとに違うため。
- 年表用に `PromoTimelineItem { year: number; title: string; summary: string; sourceUrl: string }` を別ファイル（`timeline.json`）に持つ。
- スキーマ検証にライブラリ（zod など）を使うかどうかは ARCHITECTURE.md 次第。追加が必要ならリードに提案する。
- 上記の `MotionAsset` には、リードの決定により reduced-motion 用の静止画 `still: string`（`*_still.webp`）を加える（ARCHITECTURE.md の契約を正とする）。

## 7. リスク・前提

### 7.1 権利
| リスク | 対応 |
|---|---|
| 画像・動作素材の著作権は Devsisters にある | 個人のローカル利用に限る。素材は `.gitignore` に入れて配布しない。リポジトリを公開する場合も素材は含めない。画面に「© Devsisters」を出す。 |
| wiki 本文は CC BY-SA 4.0 | 本文を転載せず、手作業で要約する。要約は派生物とみなされる可能性があるので、出典 URL とライセンス表記を各キャラに出す（AC-17）。 |
| 宣伝ページという名前 | 実際に宣伝・公開はしない。「非公開の練習用ページ」とする。外に出す場合は、権利の確認からやり直す。 |
| wiki への負荷 | スクリプトは開発時に 1 回だけ実行する。リクエストの間隔をあけ、連絡先付きの User-Agent を付ける（MediaWiki API Etiquette に従う）。 |

### 7.2 素材が欠けている場合
- オーブンブレイクの一部キャラには動作 GIF がない。代替演出（M-07, AC-27）を前提とする。
- キングダムの動作 GIF は 1 キャラ約 50 種あるが、v1 で取り込むのは **1 キャラ最大 6 種程度**（`idle` / `battle_idle` / `run` / `skill1` / `skill2` など）に絞り、容量と変換時間を抑える。
- 8MB 級の GIF は、WebP に変換しても大きいままの可能性がある。AC-09 で上限を監視し、超えたら解像度やフレームを間引く。
- wiki のファイル名の規則（`Cookie<ID>-*` / `Crob_<name>_*`）が揺れている可能性がある。スクリプトは取得できなかったものを一覧で報告し（AC-07）、その分は手で補う。
- 立ち絵が取れないキャラは、プレースホルダーで表示する（AC-59/62）。

### 7.3 前提・仮定（企画担当からリードへの確認事項）
1. **タブとタイトルフィルタの関係**: プロジェクトカードの「タイトルでの絞り込み」は、タブ切替で満たすと解釈した（タブとは別にタイトルフィルタは置かない）。
2. **キャラの単位**: 両方のタイトルにいるキャラは、タイトルごとに別エントリにする（`baseId` で結ぶ）。代表 10 体の内訳（例: キングダム 6 体、オーブンブレイク 4 体）は決まっていない。
3. **優先度**: スキル演出・慣性・傾き・揺れは Should にした。プロジェクトカードでは決定事項だが、「これがないと図鑑として使えない」機能ではないため。v1 で全部実装する前提なら、Must に上げてよい。
4. **素材の配信パス**: `/assets/...` を `public/assets/`（gitignore 対象）に置く前提で書いた。ARCHITECTURE.md と違う場合は合わせる。
5. **技術のバージョン**: プロジェクトカードの値をそのまま参考として載せた。最新版・公式情報との突き合わせは ARCHITECTURE.md の担当範囲とし、この PRD では行っていない。
6. **ルーティング**: 2 画面とするため、ルーターライブラリを使うか簡易な自前実装にするかは ARCHITECTURE.md で決める（AC-63 の 404 表示はどちらでも満たせる）。
7. **年表の年**: 2009 / 2013 / 2016 / 2021 は概要として載せた。実装時に wiki で確認する（AC-58）。

## 8. リードの決定事項（企画担当の確認事項への回答）

1. **Should の機能も v1 で実装する。** 慣性（S-01）、傾きと光沢（S-02）、待機中の揺れ（S-03）、スキル演出（S-04）、URL 同期（S-05）を今回作る。区分は Should のままにする。
2. **タブとタイトルフィルタは兼ねる。** タブ切替でタイトルを絞り込み、別のタイトルフィルタは置かない。オーブンブレイクでは役割フィルタを出さない。
3. **動作素材は 1 キャラ最大 6 種**に絞る。
4. **代表 10 体の内訳はキングダム 6 体、オーブンブレイク 4 体**とする。
5. **MotionPrefToggle（演出の強さを画面で切り替える機能）は作らない。** OS の prefers-reduced-motion にだけ従う。
6. 素材の配信パスは `/assets/{crk|crob}/{slug}/...`（`public/assets/`、gitignore 対象）で確定。ルーティングは自前の小さなルーターとする。
7. 等級の列挙値は、取得スクリプトの実データで確定する。未知の等級は Common の色で代用する。
