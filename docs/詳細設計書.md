## 2. ルーター（`src/app/router.tsx`） ✅
- `Route = "/" | "/promo" | "notfound"`。`window.location.pathname` から決める。
- `useRoute()` は `{ route, navigate }` を返す。`navigate(to)` は `history.pushState` のあと、状態を更新する。`popstate` を購読して戻る・進むに対応する。
- `Link` は通常のクリックだけを横取りする。修飾キー（Meta/Ctrl/Shift）や右クリックはブラウザの動作に任せる。
- 満たす AC: AC-56（CTA で `/` へ）、AC-57（相互リンク）、AC-63（404）。

## 3. 状態管理（`src/features/dex`） 🔲
React 標準のみ（`useState` / `useReducer`）。

| 状態 | 型 | 保持場所 | 備考 |
|---|---|---|---|
| `game` | `GameTitle` | URL `?game=` | タブ切替は `pushState` |
| `selectedId` | `string \| null` | URL `?c=` | キャラ切替は `replaceState`（履歴を汚さない） |
| `view` | `"card" \| "stage"` | URL `?view=` | |
| `query` | `string` | メモリ | URL に載せない。タブ切替でも保持（AC-13） |
| `gradeFilter`, `roleFilter` | `Set<string>` | メモリ | AND で絞り込む（AC-39） |
| `motionId` | `string` | メモリ | ステージの現在の動作 |
| `skillTrigger` | `number` | メモリ | 連番。変化でスキル演出を1回再生 |

導出: `visible = characters.filter(game).filter(search).filter(grade).filter(role)`。選択中のキャラが `visible` から消えたら、先頭を選ぶ。0件なら空の状態を出す（AC-41）。

## 4. 検索（`src/lib/normalize.ts`, `search.ts`） 🔲
- `normalize(s)`: `s.normalize("NFKC")` → 小文字化 → カタカナをひらがなに変換（`U+30A1–30F6` を `−0x60`）→ 前後の空白を除去。半角カナと全角英数は NFKC で統一される（AC-35, 36）。
- `matches(character, query)`: `names.ja`、`names.en`、`names.ko`、`aliases` を `normalize` し、`includes(normalize(query))` で判定する。空のクエリは全件に一致する（AC-37, 38）。
- 等級・役割のフィルタは、`rarity` と `role` の一致で判定する。オーブンブレイクで `role` が全員 `undefined` のときは、役割フィルタを出さない（AC-42）。

## 5. 3D 回転カード（`CharacterCard3D`） 🔲
- 構造: 外側 `perspective: 1200px`。内側の要素に `transform-style: preserve-3d` と `rotateX / rotateY`。表面と裏面は `backface-visibility: hidden`、裏面は `rotateY(180deg)`。
- 状態: `rotateY`（MotionValue）、`tiltX/tiltY`（ポインタ追従）。
- ドラッグ: `onPan` の `delta.x × 0.5°/px` を `rotateY` に加える（AC-18）。
- 慣性: ドラッグ終了時に `animate(rotateY, target, { type: "inertia", velocity, power: 0.6, timeConstant: 600 })`。速度は ±1440°/s に制限する。速度が小さいときは慣性を付けない（AC-21）。
- 表裏の判定: `((rotateY % 360) + 360) % 360` が 90〜270 のとき裏面（AC-19）。
- 正面に戻す: ダブルクリックまたは[正面]で `rotateY` と傾きを 0 に（`spring.snappy`、AC-20）。キャラ切替でも 0 に戻す（AC-24）。ステージ表示からカード表示へ戻したときも 0（AC-29）。
- 傾き: ポインタ位置から ±12° を算出し `spring.tilt` で追従。カード外に出たら 0 に戻す（AC-22）。
- 待機の揺れ: 3秒間操作がなければ `y` を 0↔-6px で往復。操作で止める（AC-23）。
- ドラッグの代替: [裏返す]（+180°）、Space、Home（UI.md 6章）。
- reduced-motion: 慣性・傾き・揺れを止める。離した位置でそのまま止まり、0°/180° への補正もしない（AC-47。受け入れ基準を正とする。2026-10-16 決定）。ドラッグでの回転とダブルクリックでの正面戻しは使える。

## 6. ステージ表示（`ActionStage`, `FallbackActor`） 🔲
- 動作の選択肢は `character.motions`。キングダムは idle/battle_idle/run/skill1/skill2/joy、オーブンブレイクは run/jump/double_jump/slide などから最大6種。
- 表示は `<img src={motion.src}>`。切替は 120ms のクロスフェード。読み込み失敗（`onError`）はその動作だけ `FallbackActor` に切り替え、トーストを3秒出す（AC-61）。
- `motions` が空のキャラは `FallbackActor`。動作ごとの transform は UI.md 5章の表に従う（跳ねる、つぶれて伸びる）。`data-fallback-motion` 属性を付ける（AC-27）。
- キャラ切替時は最初の動作（`idle` → `run` → 代替）に切り替える（AC-28）。
- reduced-motion: 最初は静止画（`still`）を出し、動作ボタンを押したときだけ WebP を再生する（AC-49）。

## 7. スキル演出（`SkillFx`, `ParticleCanvas`, `SkillCutIn`） 🔲
タイムライン（合計 約1.2秒）:

| 時刻 | 内容 |
|---|---|
| 0〜150ms | 白いフラッシュ（opacity 0→0.6→0、1回だけ。AC-34） |
| 0〜300ms | ステージの揺れ（最大 8px から減衰） |
| 0〜900ms | 粒子 80〜120個を中心から放射（重力あり。等級色とゼリー色。最大160個） |
| 100ms〜 | スキル名のカットイン（滑り込み 250 → 停止 600 → 抜ける 250） |

- `skill1` の素材があれば、演出中はそれに切り替え、終わったら直前の動作に戻す。なければ「つぶれて伸びる」で代替（AC-33）。
- 連打時は演出を1つだけ再生し、ボタンは演出中は無効にする（AC-32）。
- `ParticleCanvas`: `requestAnimationFrame` で更新。DPR の上限は 2。`visibilitychange` で非表示中は止める。演出が終わったら Canvas を非表示にする（AC-31）。
- 点滅の抑制: フラッシュは 1秒に3回を超えない。
- reduced-motion: フラッシュ・揺れ・粒子を出さず、スキル名だけ 800ms 表示（AC-48）。

## 8. 宣伝ページ（`PromoHero`, `TimelineSection`, `CtaSection`） 🔲
- `PromoHero`: `public/promo/hero.mp4` を `<video muted loop playsInline autoPlay>` で再生。`error` を受けたらポスターとタイトルのアニメーションに切り替える。例外は出さない（AC-51, 52）。
- `TimelineSection`: 高さ 400vh、中身は `position: sticky; top: 0; height: 100svh`。`useScroll({ target })` の進捗 `p`（0〜1）を使う。
  - 走るキャラ: `x = useTransform(p, [0,1], ["-20vw","120vw"])`（AC-54）。スクロールに連動し、時間には連動しない。
  - 背景の視差: 3層を係数 0.2 / 0.5 / 1.0 で動かす。
  - カードの出現: `p` が 0.15 / 0.35 / 0.55 / 0.75 を超えたら順に y 24→0、opacity 0→1（AC-55）。
- 年表データ（`timeline.json`）の年は、実装時に cookierun.wiki で確認し、`sourceUrl` に出典を書く（AC-53, 58）。
- reduced-motion: 走るキャラは静止画、年表は最初から全表示（AC-50）。

## 9. 素材の取得・変換（`scripts/fetch-assets.mjs`） 🔲
手順:
1. `characters.json` から対象キャラを読む（取得対象は JSON に書かれたキャラだけ）。
2. MediaWiki API で、各キャラのインフォボックス項目（rarity、role、position、releasedate など）と画像一覧を取得する。キングダムは `prop=images&titles=<名前>/Kingdom/Gallery` で GIF を絞る。命名は `Cookie<ID>-<動作>.gif`。オーブンブレイクは `Crob_<名前>_<動作>.gif`。
3. 画像は `prop=pageimages&piprop=original` の原寸 URL から取得する。
4. sharp で `animated: true` の GIF を WebP に変換する（`quality`、`effort: 6`、`loop: 0`）。1コマ目を `still` として出力する。立ち絵は `illustration.webp`、サムネは幅 300px の `thumb.webp`。
5. 出力先は `public/assets/{crk|crob}/{slug}/`。
6. 1ファイルが 3MB を超えたら、警告にファイル名とサイズを出す（AC-09）。

規則: リクエストは逐次、1秒間隔。User-Agent は `.env` の `WIKI_USER_AGENT`。結果は `.asset-cache/` にキャッシュ。取得できなかった素材は「キャラ ID と素材名」の一覧を出し、終了コードは 0（AC-07）。`.env` がなければ設定方法を表示して終了する。

## 10. データ検証（`tests/unit/data.test.ts`） 🔲
`characters.json` に対して次を検査する（AC-01〜06）: 必須項目、`id` の形式と一意性、`title` の値、`sourceUrl` が `https://cookierun.wiki/` で始まること、`license.text` が `"CC BY-SA 4.0"`、キャラ数 8〜12 と各タイトル 3 件以上、`motions` の `id` の一意性と `src` が `/assets/` で始まること。
