# 宣伝ページの動画（Claude Motion）制作ガイド

`/promo` の先頭にある動画枠に入れる MP4 を、claude.ai の **Claude Motion** で作るための絵コンテとプロンプト案。

## 前提と注意
- Claude Motion は claude.ai 側の機能（2026年10月8日にベータ公開と報じられている）。**Claude Code からは動画を書き出せない**ので、動画はご自身が claude.ai で作る。
- 公式の発表は確認できていない（報道記事のみ）。社内アカウントで使えるか、対象プランかどうかは、情報システム部門に確認する。Enterprise では、管理者が有効にするまでオフの場合がある。
- 動画はコードでアニメーションを組んで MP4 に書き出す方式（動画生成モデルは使わない、と報じられている）。
- 画像・GIF の著作権は Devsisters にある。**この動画も非公開・個人利用に限る**。公開・配布しない。ゲームの画像をそのまま取り込むときは、ご自身のローカルのファイルだけを使う。

## 仕様
| 項目 | 値 |
|---|---|
| 長さ | 20〜30秒（ループ再生される） |
| 比率・解像度 | 16:9、1920×1080 |
| 音声 | なし（`muted` で再生される） |
| ファイル | MP4（H.264）。目安 10MB 以下 |
| 置き場所 | `public/promo/hero.mp4` |
| ポスター画像 | `public/promo/hero-poster.webp`（動画の1コマ目などを書き出す。動画が読み込めないときの代替表示に使う） |
| 雰囲気 | 暗めの「夜のオーブン」（背景 `#1A1210`、オレンジ `#FF8A3D`、バター `#FFC845`、ピンク `#FF6FA8`、文字 `#FFF4E6`） |
| フォント | Fredoka（英数字）、M PLUS Rounded 1c（日本語の見出し） |

## 絵コンテ（約24秒）
| 秒 | 場面 | 画面 | 動き |
|---|---|---|---|
| 0–3 | オープニング | 暗い背景にタイトル「COOKIE DEX」。光る粒がゆっくり漂う | 文字が1文字ずつ跳ねて入る（ばね）。粒が下から上へ |
| 3–6 | 2009 | 「2009 OvenBreak」。右から左へ走る地面の線 | 数字が大きく出て、地面のストライプが流れる |
| 6–9 | 2012 | 「2012 OvenBreak 2」 | カードが下からスライドして入り、前の年は左へ抜ける |
| 9–13 | 2016 | 「2016 クッキーラン: オーブンブレイク」 | 地面の流れを速くする。キャラを置くなら勇敢なクッキーのシルエット（下記） |
| 13–17 | 2021 | 「2021 クッキーラン: キングダム」 | 背景が暖色のグラデーションに変わり、光の粒が増える |
| 17–20 | 2024 | 「2024 タワー・オブ・アドベンチャー」 | カメラが少し引く（拡大から縮小へ） |
| 20–24 | エンディング | 「あなたの好きなクッキーを、回して、動かして。」→「COOKIE DEX」 | 全体が暗くなり、タイトルが中央に集まって光る。最後のコマが1コマ目と似るようにして、ループを自然にする |

年と作品名は `src/data/timeline.json` と同じ内容（出典は cookierun.wiki）。変更したときは、動画の文言も合わせる。

## Claude Motion に貼るプロンプト案
```
24秒、16:9（1920×1080）、音声なしのモーショングラフィックス動画を作ってください。
テーマ: 「クッキーラン」シリーズの歴史を紹介する、キャラクター図鑑「COOKIE DEX」のオープニング。
配色: 背景 #1A1210（暗いココア）、主役の色 オレンジ #FF8A3D、バター #FFC845、ピンク #FF6FA8、文字 #FFF4E6。
フォント: 見出しは Fredoka と M PLUS Rounded 1c。丸くて親しみやすい雰囲気。

構成（秒数は目安）:
0-3 秒: タイトル「COOKIE DEX」。1文字ずつ弾むように登場。背景に光る粒がゆっくり上昇。
3-6 秒: 「2009 OvenBreak」。年の数字を大きく。画面下の地面のストライプが右から左へ流れる。
6-9 秒: 「2012 OvenBreak 2」。新しいカードが下からスライドして入り、前のカードは左へ抜ける。
9-13 秒: 「2016 クッキーラン: オーブンブレイク」。地面の流れを速くして疾走感を出す。
13-17 秒: 「2021 クッキーラン: キングダム」。背景が暖色のグラデーションに変わり、光の粒が増える。
17-20 秒: 「2024 クッキーラン: タワー・オブ・アドベンチャー」。カメラがゆっくり引く。
20-24 秒: 「あなたの好きなクッキーを、回して、動かして。」のあと、「COOKIE DEX」が中央で光る。最後の画面は冒頭に近づけ、ループ再生で自然につながるようにする。

動きの方針: 緩急をつけたばね系のイージング。すべての場面転換は 300〜600ms。点滅や急激な明滅は避ける（1秒に3回を超えない）。
キャラクターの絵は描かず、図形とテキストと光の粒だけで構成する。
最後に MP4（H.264）で書き出す。
```
- キャラクターの絵は、プロンプトでは描かせない方針にしている（著作物を新たに作らせない）。キャラを出したいときは、`public/assets/` にあるご自身のローカルの画像を、claude.ai の画面でアップロードして使う（非公開用途に限る）。

## 取り込み手順
1. claude.ai の Claude Motion で上のプロンプトを使い、動画を作る。必要ならチャットで調整する（「2016 の場面を速く」など）。
2. MP4 を書き出し、`public/promo/hero.mp4` に置く。
3. 動画の1コマ目などを画像にして、`public/promo/hero-poster.webp` に置く（任意。代替表示に使われる）。
4. `npm run dev` で `/promo` を開き、先頭で動画が自動再生・ループすることを確認する。ファイル名を間違えると、動画の代わりに代替表示（タイトルのアニメーション）が出る。
5. `public/promo/` は `.gitignore` 済みなので、コミットされない。

## 動画がないとき
動画がない状態でも `/promo` は壊れず、先頭にタイトルのアニメーションが出る（受け入れ基準 AC-52）。
